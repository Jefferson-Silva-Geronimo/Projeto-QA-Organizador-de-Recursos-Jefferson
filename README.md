# Organização de Recursos

## Objetivo

Aplicação que organiza a alocação de **salas, professores e materiais** sem conflitos de horário, desenvolvida com Java 21, Spring Boot 3.x e PostgreSQL, com front end em React.

O foco do projeto é apresentar evidências objetivas de qualidade, segurança, rastreabilidade e desempenho, conforme a [especificação do projeto](https://afonsolelis.github.io/aulas_senac/pages/qualidade2/especificacao-projeto.html).
